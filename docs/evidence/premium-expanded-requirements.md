## Proposed public medication iOS route

The smallest zero-paid-path architecture is an independent **public** `ilac-vakti` Flutter repository with synthetic fixtures, its own Brain and no private Git dependency. Preserve the existing private `napp_kit` repository. Public compute cannot fetch its private packages without additional access; do not publish/vendor private shared source or inject credentials to solve that. Prefer an app-owned standard Flutter implementation and appropriately licensed public dependencies. Existing shared source has GPL-3.0 license text: copying covered source requires license/provenance/notice and applicable source obligations; public visibility alone is insufficient.

Copy the existing opt-in simulator template into that selected app only. The public-repository guard plus `STORE_AUTOMATION_PUBLIC_CI_APPROVED=true` authorizes publication of synthetic screenshots, not paid private usage. Keep standard `macos-latest`, no artifact/cache/package/LFS upload and no private override. Official billing references and checked date are in `references/ios-ci.md`: public standard compute and built-in logs are the documented free transport; private allowance is not assumed. Retrieve bounded logs locally with native `gh`, extract with `ios-evidence.py`, bind repository/run/source SHA and inspect the actual PNG. A skipped job, successful extraction or screenshot alone is not iOS product acceptance.

Concrete native blockers before delivery/release:

- Reconcile `PB-015`'s current **private** repository step with the proposed public-only route; parent owns Brain. Record deliberate public-source/synthetic-fixture selection before creating/enabling CI. Do not change visibility of existing private repositories.
- Implement the medication product and its independent tests first. Verify offline schedule/timezone/DST/reboot/permission-denial behavior on actual selected platforms, caregiver separation, persistence and accessible navigation; avoid dosage advice and fabricated medication facts.
- Audit all dependency sources/license notices and public source/logs for secrets or real health data. No selected public repository, dependency graph or public-data approval has yet been verified.
- Execute unsigned iOS build/launch and inspect real screenshots; then exercise medication workflows. macOS simulator evidence does not prove signed device builds, background alarm reliability or App Store readiness.
- Supply selected bundle/package IDs, publisher/account mapping, native signing integration, remote version/track, legal/privacy URLs, localized complete metadata and platform-correct screenshots. Validate final merged artifacts and actual privacy/health declarations with current official policies.
- Establish any required notification/OCR/export platform entitlements and trusted native credentials without exposing their contents. Complete exact authorized store operations, read back remote status and distinguish review submission from production availability.
