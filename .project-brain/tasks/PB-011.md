## Steps

2. Provision dedicated OS service/CI identity with ACL-protected secret files and private raw logs, inaccessible to interactive agent identity; use established native secret management where available.

5. Reuse authentication until expiry; official interactive login remains user-owned. Record only references/status, never values.
