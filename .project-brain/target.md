# Target Architecture
Status: CONFIRMED
## Goal
"Belgeye göre AI App Factory sistemini gerçekten kurmandır. Mevcut kodları koru, gereksiz skill'leri güvenli biçimde temizle, ücretli AI API kullanma ve yaptığın her işi gerçek testlerle doğrula. Yalnızca rapor hazırlayıp durma. Kurulumu mümkün olan noktaya kadar tamamla." (user)
## Target State
### factory
- Three critiques and roadmap; sequential native supervisor/worker/reviewer.
- Existing Brain/Fastlane integration; persona/contracts/model policy/evidence.
- Real delegation, independent review, resume, controlled fallback/permission checks.
- Audited napp template, mode regression, real build; unavailable steps explicit.
## Non-Goals
- Example app, paid AI, uncontrolled backend deployment, production publication.
## Open Decisions
- Future app monetization/backend choices belong to app intake.
- macOS/Xcode, store products and verified subscription backend need external setup.
## Success Conditions
- Installed OpenCode discovers files; stdlib negative gate tests pass.
- Real delegation/review and fresh resume have retained logs.
- Template tests/analyze/build verified where environment allows.
- Every unavailable acceptance has blocker and next command.
