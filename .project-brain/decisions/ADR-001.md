# ADR-001 — Installed skill, project-owned state and optional hosts
Status: Accepted
## Context
User requested each application remain independent of store-otomaston, with Store Automation loading Project Brain as a skill dependency. User additionally authorized official subscription CLIs, missing official CLI installation and lightweight routing for simple work. Previous ROOT=tool-directory and bootstrap confinement could not satisfy that goal.
## Decision
Install self-contained store-automation resources in Codex/OpenCode skill directories. Runtime BUNDLE is immutable tool resources; ROOT is selected current project. Each app owns Git/Brain/contracts/evidence. Bootstrap takes a new explicit destination and preserves generated notes before retaining only canonical Brain. Existing projects/probes are not moved.
The current conversation assistant normally supervises and reports directly. Other orchestrators are optional user choices. Native host tools or approved official CLIs execute tasks; OpenCode is an optional measured adapter, not a required engine. Keep persona/model separate and route deterministic/light/standard/strong work conservatively.
## Rationale
Independent installed-runtime tests validate sibling task IDs and reject cross-project contracts/junctions. Native OpenCode worker/reviewer smoke runs outside this checkout. Account/version/model listing do not prove usable inference or included billing.
## Alternatives
- Central app workspaces/Brain: rejected because projects depend on the factory repository.
- Copy all tooling into every project: unnecessary duplication and upgrade drift.
- Universal custom multi-provider client: unnecessary new abstraction; official CLIs have distinct auth, permission and result contracts.
## Consequences
Shared starter/core/publishing protocols remain external reusable tools. Global configs preserved. Account-login and unverified CLI adapters stay explicit blockers; no paid API or token transfer. OpenCode-specific evidence gate does not certify other hosts' review provenance.
