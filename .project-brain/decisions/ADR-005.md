# ADR-005 — Cached pool, director reporting and complete product delivery
Status: ACCEPTED
Date:2026-10-12

## Context and evidence
User explicitly replaces automatic rescans and broken agent UI with cached model selection and director announcements; expands goal to full product/frontend/backend/store/marketing delivery and iterative architecture criticism. Previous skill required repeated inventory and custom console. Independent review found quota failure could erase models, native/free paths bypassed common gates, and installation retained retired UI files.

## Options and choice
Keep existing catalogue/account/routing/contract/Brain components; separate persistent discovered pool from volatile account gates. Create project-local catalogue once; explicit user scan replaces it. Corrupt/unsafe pool fails with repair instruction. Refresh supported account gates without rediscovering model lists. Quality floor precedes economy, including director's own family; no pretend active-chat model switch.
Remove custom console/team/native-terminal launch rather than maintain a second UI/controller. Preserve contained native RPC/session and image provenance primitives. Unverified free execution fails closed. Director announces assignments and collects reports in conversation.
Reuse lifecycle/publishing and add concise product-delivery and architecture-review references. Architecture review iterates on substantiated findings until required gates pass; external blockers checkpoint rather than endless retries/perfection claims. Backend/media/store tools stay conditional and native; no paid API, credentials or universal adapter invented.

## Impact
Supersedes ADR004 UI/discovery cadence only; ownership, shared admission, exact permissions and independent review remain. PB-019/PB-028/PB-029 UI-only work withdrawn by user, not accepted as completed; historical scope remains in Git. PB-020/PB-023/PB-035 retain native account/transport work without custom display requirements. Other provider/app tasks remain untouched. PB-037 runtime removal/cache; PB-038 protocol and2.4.0 rollout. No external app production authorization implied.

## Verification
Cache/reuse/explicit scan/corrupt data, outage/recovery, quota-only RPC, risk/boot checks and safe installer migration have runnable regressions. Fresh independent reviews required; release evidence records source/test/actual native limits and installed/remote hashes.
