# ADR-002 — Premium workflow using native sessions
Status: ACCEPTED

## Context
User requested global launch, visible/intervenable agents, task-specific personas, usage-aware routing, adoption, publishing preparation and GitHub delivery. Audits found installer without shell launcher, blocking execution, absent share action and incorrect cloud privacy text, and presence-only release preflight.

## Decision
Reuse installed official CLIs and Windows Terminal for real native session visibility; one Brain per selected project, separate execution records per agent. Preserve validated worker scope and independent review. Add no custom uploader or credential schema: D:/AppPublishing/README.md remains canonical. Unknown provider usage and access remain unknown; partial writes require supervisor reconciliation before fallback. Prepare GitHub delivery; official login is external.

## Consequences
No per-agent Brain, invented remaining quotas, paid API fallback, copied project history or claim that same-user secret files are inaccessible to agents. Native host workflow remains usable without OpenCode. Template modules remain optional dependencies and quality requires runnable checks.
